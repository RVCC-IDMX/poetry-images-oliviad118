# Evidence Folder

This folder contains the required screenshots for the Poetry Interpretation project.

## Required Screenshots

### For Specification 2 (HTML)

- **w3c-validation.png** - Screenshot showing W3C HTML validator results with 0 errors

### For Specification 4 (Deployment)

- **netlify-live.png** - Screenshot showing deployed site on Netlify

## Instructions

### Taking the W3C Validation Screenshot

1. Open the W3C Nu HTML Checker: https://validator.w3.org/nu/
2. Choose "Validate by File Upload"
3. Upload your `index.html` file from your project folder
4. Click "Check"
5. Take a screenshot showing **"Document checking completed. No errors or warnings to show."**
6. Save the screenshot as `w3c-validation.png` in this folder

### Taking the Netlify Screenshot

1. After deploying your site to Netlify (Specification 4)
2. Visit your live site URL
3. Take a screenshot showing your poem webpage live on the internet
4. Save the screenshot as `netlify-live.png` in this folder

---

_These screenshots serve as evidence that you've completed the validation and deployment requirements._

## How to Take Screenshots

### Mac

- Selected area: `Cmd + Shift + 4`

### Windows

- Snipping Tool: `Windows + Shift + S`

### Chromebook

- Partial: `Ctrl + Shift + Show Windows`
